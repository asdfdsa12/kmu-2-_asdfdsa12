### 공통점

모든 경우에서 선택과 버블 정렬은 비교 횟수가 1회당 49,995,500번으로 동일하고, 조기 종료 버블 정렬의 경우에는 역순으로 정렬된 데이터를 제외하고 일반 버블 정렬보다 적은 비교 횟수를 가진다.

이는, (n-9999, n-9998)부터 시작해 (n-1, n)번 원소를 비교하는 방식인 버블 정렬과 정렬되지 않은 모든 원소를 비교하는 선택 정렬의 방식이 같은 비교 횟수를 가지기 때문이다.

조기 종료 버블 정렬의 비교 횟수가 일반 버블 정렬보다 적은 이유는, 1회의 순회중 원소의 이동이 발생하지 않으면 모든 데이터가 정렬된 것으로 판단하여 정렬을 중단하기 때문이다.

삽입 정렬의 비교 횟수가 다른 정렬보다 적은 이유는, 순회시 본인보다 작은 원소와 비교할 시 순회가 중단되고 다음 순회를 진행하기 때문이다.

삽입 정렬과 버블 정렬의 이동 횟수가 비교 횟수보다 많은 경우가 있는데, 이는 데이터 스왑시 임시 변수 저장부터 최종 변수 대입까지의 모든 과정을 1회 이동으로 간주하기 때문이다.

## 정렬 알고리즘 안정성 검증
 
### 사용한 방법
 
각 데이터에 원래 입력 순서를 나타내는 번호 order를 추가하였다. order는 정렬에 영향을 주지 않는다.

정렬이 끝난 배열을 앞에서부터 훑으며 인접한 두 데이터의 key 1이 같은 경우를 찾고, 앞의 데이터의 order가 뒤의 데이터보다 크다면 순서 역전으로 간주한다.

만약 역전이 0건이면 안정, 1건 이상이면 불안정으로 판정하여 안정 여부를 출력하고 불안정시 첫번째 역전 사례를 함께 출력한다.

### 사용한 입력 데이터

데이터 1,000개, Key 1와 Key 2는 0~49 범위의 난수를 사용하였다.

키 값 하나당 평균 약 20개씩 중복되고, 모든 알고리즘에 동일한 입력의 복사본을 사용하였다.

### 각 정렬의 안정성 검증 결과

#### 선택 정렬

순서 역전 310건이 발생하였고, 그 예로는 `(2,26)#736`이 `(2,8)#39`보다 앞에 위치하였다. (#번호는 order)

선택 정렬은 최솟값을 현재 위치와 멀리 떨어진 위치끼리 직접 교환한다. 그렇기에 교환중 중간에 있는 같은 키 데이터를 건너뛰어 순서를 바꾸었고, 해당 역전이 일어나 불안정하게 되었다.

#### 버블 정렬

순서 역전 0건이 발생하였고, 조기 종료 버블 정렬도 동일하다. 조기 종료는 교환 조건을 바꾸는 것은 아니기 때문이다.

버블 정렬은 Key 1이 같은 인접 데이터는 교환되지 않으므로 서로를 추월할 수 없고, 그렇기에 order의 역전 또한 발생하지 않는다.

#### 삽입 정렬

`>`을 사용한 정렬의 경우 순서 역전 0건이 발생하였다.

`>=`을 사용한 정렬의 경우 순서 역전 950건이 발생하였고, 그 예로는 `(0,24)#990`이 `(0,42)#923`보다 앞에 위치하였다.
 
##### 삽입 정렬에서 `>`와 `>=` 사용에 따른 차이
 
`>` 를 쓰면 버블 정렬과 같이 같은 키의 데이터끼리는 서로 교환되지 않기에 order의 역전이 발생하지 않는다.

`>=` 를 쓰면 키가 같은 데이터도 한 칸씩 뒤로 밀리고, 그렇기에 order의 역전이 발생할 수 있게 된다.

## 각 정렬 알고리즘의 성능 차이

무작위 데이터 100회 정렬의 경우 비교 횟수는 삽입 정렬이 다른 정렬에 비해 약 2배 낮았는데,
이는 정렬된 상태가 아닐때 다른 정렬들은 기본적으로 한 데이터에서 어느 한 쪽 끝까지 비교를 진행하지만,
삽입 정렬의 경우 비교하는 원소가 교환 조건을 만족하지 않으면 즉시 해당 원소의 비교를 중단하기 때문이다.

이동 횟수의 경우, 선택 정렬은 비교 과정에서 이동이 발생하는 것이 아닌, 비교가 모두 끝난 뒤 원소의 이동이 발생하므로 이동 횟수가 다른 정렬보다 적다.

반면 버블 정렬은 비교시 교환 조건을 만족하면 교환을 하는 방식이기 때문에, 1회 순회당 수많은 교환이 발생할 수 있고, 그렇기에 다른 정렬 방식보다 많은 이동 횟수를 가지게 된다.

따라서, 비교 횟수는 삽입 정렬, 이동 횟수는 선택 정렬이 가장 적고, 버블 정렬은 두 횟수 모두 높은 것을 확인할 수 있다.

### 초기 데이터 정렬 상태의 영향

초기 데이터가 정렬 상태일 경우, 삽입 정렬과 조기 종료 버블 정렬은 비교를 중단하는 조건이 있기 때문에 불필요한 비교 횟수가 발생하지 않게 된다

반면 선택 정렬과 버블 정렬은 정렬 상태와 관련없이 매 순회마다 비교를 중단하지 않으므로 고정적인 비교 횟수가 발생하게 된다.

역순으로 정렬된 데이터일 경우, 정렬 알고리즘의 조건이 오름차순 정렬이기에 전혀 정렬되지 않은 상태로 인식, 그렇기에 발생 가능한 최대의 비교 횟수와 이동 횟수가 발생하게 된다.

그러나, 해당 실험은 중복된 데이터의 생성이 허용되었기 때문에 최대로 발생할 수 있는 이동 횟수보단 적은 횟수가 발생하게 된다.

일부 정렬된 데이터의 경우, 정렬이 된 구간이 대부분, 정렬이 되지 않은 구간이 소수이다.

그렇기에, 데이터에 따라 비교 횟수가 다른 삽입 정렬과 조기 종료 버블 정렬의 경우, 100회 정렬을 할때 사용한 데이터보단 대체로 비교 횟수가 적게 나타난다.

이동 횟수 또한 이미 정렬된 구간이 대다수이므로, 원소가 이동되지 않는 경우가 많아 완전 랜덤 데이터보단 적게 나타난다.

결론적으로, 정렬된 데이터 < 일부 정렬된 데이터 < 역순으로 정렬된 데이터 순으로 비교와 이동 횟수가 적게 나타난다.
